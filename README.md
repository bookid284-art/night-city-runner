# Night City Runner

A neon-styled 3D driving and police pursuit game that runs in a web browser. The complete game is contained in a single HTML file, with embedded CSS and JavaScript.

## Origin

The original game source was generated by **DeepSeek** and supplied by the repository owner in a Word document. This repository extracts that source into `index.html` so it can be read, versioned, and run directly. ChatGPT assisted with extraction, repository setup, and this English README. The initial import preserves the game code; only the surrounding document heading was removed and a final newline was added.

The in-game interface and source comments are primarily in Chinese, with some English HUD labels.

## Features

- A procedural night city with neon lighting and bloom effects.
- Two game modes: Escape and Pursuit.
- Drifting, nitro boost, an EMP ability, items, and repair locations.
- Escalating wanted levels, police vehicles, roadblocks, helicopters, and spike strips.
- Three vehicle color schemes and three camera views.
- A speedometer, radar, vehicle health, nitro meter, and score display.
- Synthesized audio through the Web Audio API.
- Touch controls in addition to keyboard input.

## Run locally

Requirements: a modern browser with WebGL 2, ES module, and import map support. An internet connection is required to load Three.js and its add-ons from UNPKG.

Clone the repository, enter its directory, and start a local static server. With Python 3 installed:

```bash
git clone https://github.com/bookid284-art/night-city-runner.git
cd night-city-runner
python3 -m http.server 8000 --bind 127.0.0.1
```

Open <http://localhost:8000> in your browser. Choose a mode and vehicle color scheme, then click the yellow start button. Stop the server with `Ctrl+C` in the terminal.

No npm install, build step, application backend, or API key is needed. Use an HTTP server instead of relying on opening the HTML through a `file://` URL. The repository contains one game file, but it is not fully offline because its rendering library is loaded from a CDN.

## Game modes

### Escape

Drive the getaway car and survive police pursuit. Collisions and dangerous driving raise the wanted level and introduce stronger police responses. Once the escape conditions are met, evade detection for eight seconds to trigger an escape and a 60-second cooldown. Losing all vehicle health or being boxed in by police ends the run.

### Pursuit

Drive a police interceptor and disable the AI getaway car within three minutes.

## Keyboard controls

| Key | Action |
| --- | --- |
| `W` / Up arrow | Accelerate |
| `S` / Down arrow | Brake / reverse |
| `A` / Left arrow | Steer left |
| `D` / Right arrow | Steer right |
| Space | Handbrake / drift |
| Shift | Nitro boost |
| `Q` | EMP pulse |
| `E` | Use an item / repair near a repair location |
| `C` | Cycle camera views |
| `R` | Reset vehicle position |
| `P` | Pause / resume |
| `M` | Toggle mute |

On touch devices, the game provides a virtual steering control and on-screen driving buttons. A keyboard provides access to the full control set.

## Technology

- HTML, CSS, and JavaScript ES modules
- Three.js **0.169.0**, loaded through an import map
- Three.js postprocessing add-ons, including bloom and custom shader effects
- Canvas-generated textures and Web Audio API sound

## Validation and limitations

The initial import was checked for JavaScript syntax and a valid import map. This is an AI-generated prototype; full browser gameplay, performance, and mobile compatibility have not been verified as part of the import. If loading fails, check the browser console and whether your network can reach `unpkg.com`. Performance depends on the device and graphics capabilities.
